# 아기 잠투정 방지 백색소음 플레이어

신생아 및 영유아를 키우는 부모님들을 위한 웹 기반 백색소음 플레이어입니다. 밤중 육아나 낮잠 시간에 아기가 안정감을 느끼고 쉽게 잠들 수 있도록 돕습니다.

## 주요 기능
- **6종 백색소음**: 빗소리, 엄마 배 속 소리(심장박동), 파도 소리, 청소기 소리, 바람 소리, 폭포 소리
- **멀티 믹싱 & 개별 볼륨**: 여러 소리를 동시에 섞어서 재생하고 각 소리의 볼륨을 개별 조절
- **자동 종료 타이머 & 페이드 아웃**: 설정된 시간이 되면 소리가 5초간 서서히 작아지며 종료 (15분, 30분, 45분, 60분, 90분, 무제한 지원)
- **다크모드 UI**: 밤중 육아 시 눈부심이 없는 딥 네이비(#121826) 테마 적용
- **화면 꺼짐 방지**: 재생 중 스마트폰 화면이 꺼지지 않도록 Screen Wake Lock API 적용

## 🛠️ 비전문가용 실행 방법 (로컬 실행 가이드)

컴퓨터에 Node.js가 설치되어 있지 않다면 먼저 공식 홈페이지에서 **Node.js (LTS 버전, v20 이상 추천)**를 다운로드하여 설치해 주세요.

1. **압축 해제 및 폴더 이동**
   - 제공받은 프로젝트 압축 파일을 풀고, 터미널(명령 프롬프트)을 열어 해당 폴더로 이동합니다.
   - 예시: `cd baby-white-noise-player`

2. **필수 프로그램(패키지) 설치**
   - 터미널에 아래 명령어를 입력하고 엔터를 누릅니다.
   ```bash
   npm install
   ```

3. **개발 서버 실행**
   - 설치가 완료되면 아래 명령어를 입력합니다.
   ```bash
   npm run dev
   ```

4. **웹브라우저로 접속**
   - 터미널에 나타나는 주소(일반적으로 `http://localhost:5173`)를 클릭하거나 인터넷 창에 입력하여 접속합니다.
