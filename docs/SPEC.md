## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
- 아기가 안정감을 느끼고 쉽게 잠들 수 있도록 돕는 웹 기반 백색소음 플레이어

### 핵심 가치
- 회원가입이나 복잡한 로그인 없이 접속 즉시 사용 가능
- 어두운 방(밤중 육아)에서도 눈이 부시지 않는 다크모드 UI
- 1개의 소리만 선택하여 집중 재생하는 단일 플레이어 구조 (중복 재생 방지)
- 설정한 시간이 되면 부드럽게 소리가 작아지며 꺼지는 타이머(Fade-out)

### 주요 제공 소음 (확정)
- 토독토독 빗소리, 엄마 배 속 소리(심장박동), 시원한 파도 소리, 청소기 소리, 자연의 바람 소리, 웅장한 폭포 소리 (실제 고품질 오디오 파일 재생 방식)

## 2. 사용자와 사용 시나리오

### 주요 사용자
- 신생아 및 영유아를 키우는 부모 (특히 밤중 육아 및 낮잠 재우기 상황)

### 사용자 시나리오 (Given / When / Then)
- **시나리오 1: 백색소음 재생 및 자동 종료**
  - Given: 사용자가 메인 화면에 접속해 있다.
  - When: '빗소리'를 선택하고 타이머를 '30분'으로 설정한 뒤 재생 버튼을 누른다.
  - Then: 30분 동안 빗소리가 반복 재생되며, 시간이 종료되면 소리가 5초간 서서히 줄어들며(Fade-out) 정지한다.

## 3. 기능 명세

### 1. 단일 백색소음 리스트 선택 및 재생 기능 (오디오 파일 기반)
- 총 6종의 음원 리스트 제공 (토독토독 빗소리, 엄마 배 속 소리, 시원한 파도 소리, 청소기 소리, 자연의 바람 소리, 웅장한 폭포 소리)
- **단일 플레이어 구조**: 화면 중앙의 단일 플레이어 영역에서 리스트 중 하나를 선택하여 재생. 다른 소음 선택 시 기존 소음은 즉시 멈추고 새 소음이 단독으로 재생됨.
- **실제 오디오 파일 재생**: `public/audio/` 경로의 실제 `.mp3` 파일(`.mp3` 형태의 실제 오디오 데이터를 포함)을 브라우저 `Audio` 객체로 로드하여 무한 반복(loop) 재생
- **볼륨 조절**: 0%부터 100%까지 조절 가능한 슬라이더 제공
- **재생 시간 표기**: 플레이어 영역에 현재 재생된 총 시간(`00:00` 형식) 실시간 표기

### 2. 자동 종료 타이머 및 남은 시간 표기
- 선택 옵션: 15분, 30분 (기본), 45분, 60분, 90분, 무제한
- **남은 시간 카운트다운 표기**: 타이머 활성화 시 화면에 남은 시간(예: `28:45 남음`)을 초 단위로 실시간 표기
- 종료 5초 전부터 음량이 부드럽게 작아지는 페이드 아웃(Fade-out) 적용 후 정지

### 3. 화면 잠금 방지 (Wake Lock API)
- 재생 중 스마트폰 화면이 꺼지지 않도록 브라우저 화면 유지 기능 기본 활성화

## 4. 화면과 주소(URL) 구성

### URL 경로 구조
- `/`: 메인 플레이어 단일 페이지 (SPA 구조)

### 화면 레이아웃
- **헤더 영역**: 서비스 타이틀 및 현재 시간 표기
- **메인 플레이어 영역 (단일 플레이어)**: 현재 선택된 소음 이름, 아이콘, 재생/정지 버튼, 총 재생 시간(`00:00`), 타이머 남은 시간 표시
- **소음 리스트 선택 영역**: 6개의 백색소음 항목이 나열된 리스트 카드 (클릭 시 즉시 해당 소음으로 전환 및 재생)
- **하단 제어 영역**: 볼륨 조절 슬라이더 및 타이머 설정 버튼

## 10. 테스트 계획

### 수용 테스트 시나리오 (Given / When / Then)

1. **단일 플레이어 동작 테스트**
   - Given: 사용자가 '빗소리'를 재생하고 있다.
   - When: 사용자가 '파도 소리' 카드를 새로 선택한다.
   - Then: 기존에 재생되던 빗소리는 즉시 멈추고 파도 소리만 단독으로 재생된다.

2. **자동 종료 타이머 페이드 아웃 테스트**
   - Given: 사용자가 메인 화면에서 소리를 재생 중이고 타이머를 1분으로 설정했다.
   - When: 타이머 시간이 종료 시점(0초)에 도달한다.
   - Then: 음량이 5초에 걸쳐 점진적으로 0으로 줄어든 뒤(Fade-out) 재생이 완전히 정지한다.

3. **재생 시간 및 카운트다운 표기 테스트**
   - Given: 사용자가 백색소음 재생을 시작하고 타이머를 설정한다.
   - When: 1초 이상 시간이 경과한다.
   - Then: 상단 헤더에 총 재생 시간이 1초씩 증가하여 표기되고, 설정한 타이머의 남은 시간은 1초씩 감소하여 표기된다.

4. **화면 켜짐 유지(Wake Lock) 테스트**
   - Given: 모바일 브라우저에서 플레이어를 재생한다.
   - When: 일정 시간이 경과한다.
   - Then: Screen Wake Lock API가 작동하여 기기 화면이 자동으로 꺼지지 않는다.
